# 月下學園（開頭試玩版）

2D 類銀河惡魔城動作冒險。以白帽金髮少女為主角，在互相連通的月下學園裡探索：先看見暫時過不去的路，取得衝刺或二段跳後再走回頭打開。

與「王牌裂隙」分開的新專案。地圖與背景美術來自 `maps/`、`art/`；角色、移動、戰鬥、能力解鎖、觸控與公開頁在此目錄的 `index.html`。

## 本機遊玩

請用本機伺服器開啟（直接開檔案可能無法載入地圖）：

```bash
cd /workspace/galaxy-castle
python3 -m http.server 8080
```

然後在瀏覽器打開 <http://localhost:8080>。手機請用同一區網位址，或把網站加入主畫面。

## 操作

- 手機：左側虛擬方向；右側跳、攻擊、互動。取得衝刺後會出現衝刺鍵，也可以連點同一方向發動。
- 電腦：方向鍵或 WASD 移動，空白鍵／W 跳躍，J 攻擊，E 互動，Shift／L 衝刺。Esc 暫停，M 靜音，H 說明。
- 長椅可回復生命並設為檢查點。

## 開頭切片流程

1. 月下中庭：學會走與跳。東側斷橋與西側高台此時過不去。
2. 往西走進藤蔓西廊，取得衝刺，回到中庭衝過斷橋。
3. 東圖書館取得二段跳，再回中庭跳上高台進入鐘樓。
4. 鐘樓頂層與夜鐘守護者一戰。中庭天井可掉進舊校舍地下（有額外生命）。
